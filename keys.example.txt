# Provider API keys, one per line, for `npm run keys` - or paste the same lines
# into mains > providers in the window.
#
# The floor talks to each provider directly. Keys are kept in
# ~/.nightshift/providers.json and never sent to the browser. A file at
# ~/.nightshift/keys.txt is also read on every boot.
#
# Every key is its own lane with its own rate limit: three NVIDIA keys are three
# times the requests a minute, and a desk's work moves to whichever key is free.
#
# A bare key is matched to its provider by prefix:
nvapi-xxxxxxxxxxxxxxxxxxxxxxxx
gsk_xxxxxxxxxxxxxxxxxxxxxxxx
AIzaxxxxxxxxxxxxxxxxxxxxxxxx

# Or name the provider (nim, groq, gemini, openrouter, cerebras, mistral, deepseek, openai):
mistral = xxxxxxxxxxxxxxxxxxxxxxxx

# Any other OpenAI-compatible server: a new id, the key, and its base URL after a `|`
lab-box = key-xxxx | http://192.168.1.40:8000/v1

# Or skip the file entirely and start with environment variables:
#   NVIDIA_API_KEY=nvapi-...  GROQ_API_KEY=gsk_...  GEMINI_API_KEY=AIza...  npm start
